# Culture Travel Club

An HTML-only website for a fictional cultural travel club.
Created for Web Programming Assignment 1.

## Theme

The website introduces destinations through their history,
culture, and everyday life. Visitors can learn about the club,
browse trips, and complete an enquiry form.

## File Organization

- index.html — Homepage with two destination articles and images.
- about.html — Club purpose, a captioned image, and semantic elements.
- services.html — A table presenting five cultural trips.
- contact.html — An enquiry form with browser validation.
- assets/ — Images used on the website.
- README.md — Project description and notes.

## How to Open

Open index.html in a web browser.
Use the navigation menu to move between the four pages.

## Form Behavior

The contact form uses HTML validation and submits through GET
to contact.html. Submitted values appear in the URL.
The website does not store enquiries or send emails.
Use fictional information when testing.

## Challenges

- Understanding where new elements belong in the HTML structure.
- Keeping the navigation consistent across all four pages.
- Connecting form labels to their corresponding inputs.

## Technologies

HTML5 only. No CSS or JavaScript.
